## zh-CN

设置 `nzMaxCount` 限制最多可选中的节点数量，达到限制后未选中的节点会变为禁用状态，已选中的节点仍可被移除。

## en-US

Set `nzMaxCount` to limit the maximum number of nodes that can be selected. Once the limit is reached, not-yet-selected nodes become disabled, while already-selected nodes can still be removed.
