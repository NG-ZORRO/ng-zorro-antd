## zh-CN

设置 `nzMaxTagCount="responsive"` 时，多选标签将根据选择器可用宽度自适应折叠在单行内展示，超出部分聚合为 `+ N ...`。

## en-US

When `nzMaxTagCount="responsive"` is set, the tags will be automatically collapsed on a single line based on the available container width.
